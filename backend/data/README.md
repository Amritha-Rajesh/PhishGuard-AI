# Dataset folder

Place `PhiUSIIL_Phishing_URL_Dataset.csv` here (it is inside the `phiusiil_phishing_url_dataset.zip` you downloaded;
source: UCI Machine Learning Repository, dataset 967, licence CC BY 4.0).

The file is about 57 MB and is deliberately NOT committed to GitHub (see `.gitignore`).
`python train.py` reads it from this folder. The running web app never reads it.
